# 合成大奶娃 · 摇一摇版（重力感应）

在 [yhsome/BigNaiWa](https://github.com/yhsome/BigNaiWa)（[原版在线地址](https://yhsome.github.io/BigNaiWa/v1/)）的基础上，
只加了一个功能：**手机重力感应 / 摇一摇**。其余玩法、物理、画面、音效都和原版一样。

## 新增玩法

| 动作 | 效果 |
| --- | --- |
| **左右倾斜手机** | 水果往低的那一边滚（约 4° 以内的倾斜不算，拿手机自然有点歪不会乱滚） |
| **晃动 / 甩手机** | 水果像在真盒子里一样被惯性甩来甩去、往上蹦，可以把卡住的缝隙抖开、让同级的撞到一起合成 |
| **竖着 / 平放 / 斜着拿** | 都能正常玩：原本向下的重力保持不变，传感器只是额外加力 |

棋盘左上角有个 **📳 重力感应** 开关，点一下开 / 关（会记住你的选择）。

- **安卓**：打开就自动生效。
- **iPhone / iPad**：系统要求授权——第一次点棋盘（或点左上角红色的「点我开启重力感应」）
  会弹出「动作与方向访问」，点 **允许** 即可。不小心点了拒绝的话，把网页关掉重新打开再允许。
- **电脑**：没有传感器，开关不会出现，和原版完全一样。
- 必须是 **https** 网址才能用传感器（GitHub Pages / githack 都是 https）。

## 改了哪些文件

| 文件 | 改动 |
| --- | --- |
| `shake.js` | **新增**。读 `devicemotion`：拆出重力（倾斜）和手机自身加速度（摇晃），换算成游戏里的加速度；按屏幕旋转角换轴（横屏也对）；iOS 传感器符号和安卓相反，用 `deviceorientation` 的姿态角自动校准 |
| `shake.css` | **新增**。左上角开关的样式；有开关时把复活币胶囊往下挪一格，两者不叠在一起 |
| `game.js` | 加了 3 行：一个外加加速度 `ext = {ax, ay}`，在物理积分时加到每个水果上（关掉时为 0，行为与原版一致） |
| `index.html` | 引入 `shake.css` / `shake.js`，标题加「摇一摇版」，桌面端提示里加一句玩法说明 |
| `leaderboard.js` / `leaderboard.min.js` | 排行榜换成单独的榜（tag 前缀 `dnwyy_`），摇一摇版的成绩不和原版玩家混在一起排名 |

手感参数在 `shake.js` 顶部（`TILT_GAIN` 倾斜力度、`SHAKE_GAIN` 摇晃放大倍数、`SHAKE_MAX` 单次甩动上限等），想更疯可以调大。
